# ファイル形式と列

🌐 [English](./format.md) | **日本語**

実装済み（0.0.2）: 先頭 BOM の除去、英語 / 日本語の見出し名による列特定と先頭 9 列の位置フォールバック、空行と `#` 行の読み飛ばし、下表の列解釈と Issue（ただし `セクション名`・`値(最小)`・`値(最大)`・`備考`・`変数名`・`お気に入り` は `ChannelDef` にまだ載らず、`表示形式` は検査のみで保持しない）、`parse_*_csv_bytes` によるバイト列入力、`load_*_csv` の `AsRef<Path>` 受け取り。書き出しは全て未実装。

## 1. ファイル

| 項目 | 読み | 書き |
|---|---|---|
| 文字コード | UTF-8。先頭の BOM（`EF BB BF`）は 1 個以上あっても全て無視する | UTF-8、BOM 付き（表計算ソフトが別の文字コードと誤判定しないため） |
| レコード区切り | `\r\n` と `\n` の両方を受け付ける | `\r\n` |
| セル内改行 | 引用符で囲まれたセル内の `\n` / `\r\n` はセルの一部（RFC 4180） | 元の文字列を変えずに書く（`\n` を `\r\n` に正規化しない） |
| 引用 | `"..."`。内部の `"` は `""`。引用符の外の `"` は文字として扱う | `,` `"` `\r` `\n` のいずれかを含むセルを引用する |
| 空白 | セルの前後の空白（半角スペース・タブ）は取り除いて解釈する | 取り除かない（原文を保つ） |
| 空行 | 全セルが空の行は読み飛ばす（Issue なし） | — |
| コメント行 | 先頭セルが `#` で始まる行は読み飛ばす（Issue なし） | — |
| 空ファイル / 見出しのみ | チャンネル 0 件、Issue なし | — |

**デコードの担当**: chdef が読むのは UTF-8 だけで、文字コードの推測はしない。`parse_ch_csv` は呼び出し側がデコード済みのテキストを受け取る。`parse_ch_csv_bytes` はバイト列を受け取り、BOM を落として UTF-8 として解釈し、解釈が止まったバイト位置を返す。表計算ソフトが CP932 で書き出したファイルは、呼ぶ前に利用側がデコードする。

**引用の理由**: セル内改行を引用しないで書くと、次の読み込みで 1 行が複数レコードに割れ、続きの行が `番号` に見えない値を持つ幽霊行になる。読み側は幽霊行を `番号` の検査で捨てるが、失われた `備考` は戻らない。

## 2. 列の特定

列は **見出し名**で特定する。各列には **英語**（小文字 ASCII）と **日本語**（元の形）の 2 つの正式な綴りと別名があり、どれも同じ列を指す。見出しセルは前後空白を除き、大文字小文字を区別せずに照合する。1 つの見出し行に両言語が混ざっていてもよい。見出しに無い列は「未指定」として扱い、エラーにしない。**知らない列は保持し、そのまま書き戻す**。

見出し行が無い、または `番号` 列が見つからない場合は、先頭 9 列を CH CSV の正順（下表の順）と**みなす**（9 列形式との互換）。この場合 Issue `header_assumed` を 1 件報告する。

見出し名は読んだままの綴りで書き戻す。新規に作るファイルは、書き手に指示が無ければ英語の綴りを使う。

## 3. CH CSV

正順の見出し（16 列形式）。英語と日本語の綴り:

```
number,bytes,bits,section,name,type,lsb,offset,unit,min,max,default,memo,var,format,favorite
番号,バイト数,ビット数,セクション名,メッセージ名称,型,LSB,オフセット,単位,値(最小),値(最大),値(デフォルト),備考,変数名,表示形式,お気に入り
```

先頭 9 列 + `値(デフォルト)` だけの 9〜10 列形式も同じ規則で読む。

| 列 (ja / en) | 別名 | 必須 | 解釈 |
|---|---|---|---|
| `番号` / `number` | `no`, `CH`, `ChNumber` | **必須** | 1 以上の整数。空欄・非整数・0 以下は**行ごと読み飛ばし**（Issue `channel_number_invalid`）。全セルが空の行と `#` 行は Issue なしで読み飛ばす。上限は設けない（u32） |
| `バイト数` / `bytes` | — | 任意 | 1〜8 の整数。空欄・非整数 → `型` の幅（下記）、それも無ければ 2（Issue `bytes_assumed`）。範囲外 → 1〜8 に丸めて Issue `bytes_out_of_range` |
| `ビット数` / `bits` | — | 任意 | 読まない。保持して書き戻す |
| `セクション名` / `section` | — | 任意 | 文字列。空欄はセクション無し |
| `メッセージ名称` / `name` | `SignalName`, `信号名称` | 任意 | 文字列 |
| `型` / `type` | `DataType`, `データ型` | 任意 | 接頭辞 2 文字（大文字小文字不問）`UI` / `SI` / `BF` と、任意の幅サフィックス（`UI8` `SI16` `UI32` `SI64` …）。空欄・不明 → `UI`（Issue `type_assumed`）。幅は常に `バイト数` から決まり、サフィックスと食い違えば `バイト数` が勝つ（Issue `type_width_mismatch`） |
| `LSB` / `lsb` | `Scale`, `スケール` | 任意 | 実数。空欄・`0` → `1`。それ以外の有限値はそのまま（負も可）。非数・無限 → `1`（Issue `lsb_invalid`） |
| `オフセット` / `offset` | `基準値` | 任意 | 実数。空欄 → `0`。非数 → `0`（Issue `offset_invalid`） |
| `単位` / `unit` | — | 任意 | 文字列 |
| `値(最小)` / `min`, `値(最大)` / `max` | `最小値` / `最大値` | 任意 | 文字列として保持する。0.0 系では解釈しない |
| `値(デフォルト)` / `default` | `DefaultValue`, `デフォルト値` | 任意 | 空欄 → 未指定。`0x` / `0X` 接頭辞 → 16 進の生値。それ以外 → 10 進の**生値**（整数）。非整数 → 未指定（Issue `default_invalid`）。BF 型では BF CSV の既定値がビット単位で上書きする（[conversion.jp.md](./conversion.jp.md)） |
| `備考` / `memo` | `Description` | 任意 | 文字列 |
| `変数名` / `var` | `variable` | 任意 | 文字列。保持のみ |
| `表示形式` / `format` | `DisplayFormat` | 任意 | `DEC` / `HEX`（大文字小文字不問）。空欄・不明 → `DEC`。`HEX` で `LSB` が 1 以外なら Issue `hex_with_lsb` |
| `お気に入り` / `favorite` | `IsFavorite` | 任意 | `1` または `true`（大文字小文字不問）→ 真、それ以外 → 偽。書き出しは `1` / `0` |

`型` の接頭辞と幅の対応: 幅は `バイト数 × 8` ビット。`UI` は符号なし整数、`SI` は 2 の補数の符号付き整数、`BF` はビットの集まり（値としては符号なし）。

## 4. BF CSV

```
number,bit,name,default,memo
番号,BIT番号,メッセージ名称,値(デフォルト),備考
```

| 列 (ja / en) | 別名 | 必須 | 解釈 |
|---|---|---|---|
| `番号` / `number` | `no`, `CH` | **必須** | 親チャンネルの `番号`。空欄・非整数 → 行ごと読み飛ばし（Issue `bf_parent_invalid`） |
| `BIT番号` / `bit` | `BitNumber` | **必須** | 0 以上の整数、親の幅 `バイト数 × 8` 未満。非整数 → 行ごと読み飛ばし（Issue `bf_bit_invalid`）。幅以上 → 読み飛ばし（Issue `bf_bit_out_of_range`）。親が未定義、または親の `型` が `BF` でない → 読み飛ばし（Issue `bf_parent_not_bitfield`） |
| `メッセージ名称` / `name` | `SignalName`, `信号名称` | 任意 | 文字列 |
| `値(デフォルト)` / `default` | `デフォルト値` | 任意 | `0` / `1` のみ有効。空欄 → 未指定（親の既定値のビットを保つ）。それ以外 → 未指定（Issue `bf_default_invalid`） |
| `備考` / `memo` | — | 任意 | 文字列 |

BF CSV は `型` が `BF` のチャンネルの分だけあればよく、全チャンネルを列挙する必要はない。1 行は 1 ビット。ビット範囲（`3:1` のような複数ビット）は 0.0 系では表現しない。
