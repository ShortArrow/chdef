## 用語

- **CH（チャンネル）**: フレーム内の連続したバイト列 1 つ。`番号` で識別し、`バイト数` の幅を持つ。
- **BF（ビットフィールド）**: `型` が `BF` のチャンネルの中の 1 ビット。`(親番号, BIT番号)` で識別する。
- **生値 (raw)**: ワイヤ上のビットパターンを幅ぶんの整数に読んだもの。
- **物理値 (value)**: `生値 × LSB + オフセット`。
- **レイアウト**: 定義の並び順で先頭から詰めた各チャンネルの位置と、合計バイト数。
- **Issue**: 行・列を指して報告する診断。読み込みは止めない。

## 範囲外（chdef が持たないもの）

- 表示（DEC/HEX の描画、桁数、色）、編集 UI、保存操作の制御
- 転送（UDP / 共有メモリ / シリアル）、パケットヘッダ、パケット番号の付け替え、複数 CSV の合成
- 定義ファイルの置き場所・パス設定・再読み込みのタイミング
- 実機の定義データ。本リポジトリのサンプルとゴールデンベクタは全て合成
