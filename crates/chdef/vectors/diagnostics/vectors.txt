# A set may declare the Issues its own definitions produce. Rows are the
# 0-based data rows of diagnostics.md §1; the order Issues arrive in is
# unspecified, so a P line is a set.
#
# ch.csv row 1: `number` is "x"          -> channel_number_invalid
#          row 2: `bytes` is 99           -> bytes_out_of_range (clamped to 8)
#          row 3: `type` is "ZZ"          -> type_assumed (UI)
#          row 4: `number` 1 is taken     -> channel_duplicate
#          row 5: min 10 above max 5      -> min_max_swapped
P ch channel_number_invalid:1;bytes_out_of_range:2;type_assumed:3;channel_duplicate:4;min_max_swapped:5
#
# bf.csv row 1: `bit` is "y"              -> bf_bit_invalid
P bf bf_bit_invalid:1
#
# The cross-file checks run where the CH and BF definitions meet, so they
# carry no row (ADR-0008): channel 1 is UI, and channel 3 does not exist.
P layout bf_parent_not_bitfield:-;bf_parent_not_bitfield:-

# The row whose `number` was invalid never became a channel, and the
# duplicate is dropped by the layout, so four channels remain: the clamped
# width of channel 2 counts as 8, and channel 4 keeps its useless bounds.
